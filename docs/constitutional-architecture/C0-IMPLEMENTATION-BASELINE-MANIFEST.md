## SECTION 5 — IMPLEMENTATION CONSTRAINTS

### 5.1 Constitutional Authority Order

Implementers must apply the following authority precedence (highest first):

1. D-series documents (D-2 through D8)
2. A0-v1.1.1-canonical.md
3. A1-v1.2-canonical.md
4. R0-v1.0-runtime-specification-standard.md
5. R1 through R16 certified runtime specifications

Where conflicts exist between levels, higher levels govern. All such conflicts are disclosed in the affected runtime specifications.

### 5.2 Key Constitutional Facts (Fixed by Certification)

1. **RT-06 canonical name is "Coherence Runtime"** (not "Event Stream Runtime"). A1-v1.2 reflects this correctly.
2. **RT-07 canonical name is "Memory Runtime"** per A0 §3.8.
3. **RT-12 canonical name is "Decision Runtime"** (not "Constitutional Compliance Runtime"). A0 §3.13 governs.
4. **RT-12 owns CivilizationalDecision** (not RT-11). RT-11 owns CivilizationalDecisionProposal.
5. **RT-16 is ABSENT from all 10 standard Constitutional Loop phases.** It operates via A1 §12.8 15-step amendment execution order.
6. **RT-15 is a twelve-instance runtime.** One canonical specification (R15-v1.0-canonical.md) governs all twelve instances.
7. **D6 §4.2–4.6 AIR-N** = five authority types; **D6 §4.7 AIR-N** = Authority Integrity Rules. These are distinct systems; do not conflate.
8. **D4-v1.0 is historical only.** D4-v2.0-canonical.md is the operative projection framework document.
9. **Gate 6 uses RT-05 ChangeRecord/HistoricalAnchor history** (not RT-07 temporal record). A1-v1.2 §12.1 Step 11, §8.1 VC-6, §10.1, §14.1 all reflect this.
10. **A1 §3.6 incorrectly cites D7 §6.1** for RT-11→RT-16 interactions. The correct source is D7 Part 12. This error exists in A1-v1.2 and is inherited by R16. The constitutional substance of the amendment process is correctly derived from D7 Part 12 throughout R16-v1.0-canonical.md RS-12.

### 5.3 Not-Yet-Implemented Elements

- RT-15 DOM-000001 conditional responsibility (Temporal Coherence Bootstrapping): applies only to the first domain instance. Twelve-instance deployment must ensure DOM-000001 bootstrapping occurs before other instances initialize.
- RT-16 human governance actors: Founding-level authorization for Class I amendments (D7 §12.2) requires human actors. This is not a runtime dependency; implementers must integrate human governance checkpoints at Class I amendment initiation.
