5. AIR-4 name corrected from "Action Authority" to "Projection Authority" (per D6 §4.5, A1 §5.1, R0 §3.5).
6. AIR-5 name corrected from "Constitutional Authority" to "Audit Authority" (per D6 §4.6, A1 §5.1, R0 §3.5).

**Verification:** D6 §4.1 heading confirmed: "Constitutional Principle of Domain Authority" — introduces five types. D6 §4.4 heading confirmed: "Decision Authority" — defines that type.
