### CR-08 — RS-18.1 PRE-A-03 Cross-Reference Correction

**Deficiency addressed:** CD-02 — RT01-OBL-11 cross-reference error  
**Section:** RS-18 — Preconditions (§18.1 PRE-A-03)  

**v1.0:** `pending RT-03 restoration per RT01-OBL-11.`  
**v1.1:** `pending RT-03 restoration per D4 §2.1 (Kernel Mediation Principle).`

**Reason:** RT01-OBL-11 is "Founding Membership Registry Maintenance" — the obligation to maintain founding records at civilization root. It has no bearing on RT-03 unavailability behavior. The constitutional basis for suspending Class A operations when RT-03 is unreachable is D4 §2.1 (Kernel Mediation Principle), which requires all Class A operations to pass through the Kernel. When the Kernel (RT-03) is unavailable, Class A operations are suspended per KMP, not per RT01-OBL-11.  
**Constitutional basis:** D4 §2.1 (Kernel Mediation Principle); A1 PAIR 02  
**Certification impact:** CD-02 partial resolution

### CR-12 — D8 Invariant Naming Correction

**Deficiency addressed:** SD-03 — D8-INV-N naming deviation  
**Sections affected:** RS-20 (section headers and body text), RS-21, RS-25  

**Pattern replaced:** `D8-INV-N` → `INV-N` (where N = 1 through 7)  
**Total replacements:** All occurrences of D8-INV-1 through D8-INV-7 in the specification body

**Specific identifiers corrected:**
- D8-INV-1 → INV-1 (Identity Observability Invariant)
- D8-INV-2 → INV-2 (Provenance Completeness Invariant)
- D8-INV-3 → INV-3 (Authority Derivation Invariant)
- D8-INV-4 → INV-4 (Constitutional Constraint Invariant)
- D8-INV-5 → INV-5 (Audit Completeness Invariant)
- D8-INV-6 → INV-6 (Translation Integrity Invariant)
- D8-INV-7 → INV-7 (Separation of Concerns Invariant)

**Reason:** R0 §5.9 INS-2 specifies the format for D8 system invariants as "INV-N" (no document prefix). The "D8-" prefix was added non-standardly during writing. The correction ensures all invariant identifiers conform to R0 §5.9 INS-2.  
**Safety note:** Document section references ("per D8 INV-N" with space, not hyphen) were not altered — only the formal identifier pattern `D8-INV-N` (hyphenated) was replaced.  
**Certification impact:** SD-03 resolved; R0 §5.9 INS-2 compliance restored
