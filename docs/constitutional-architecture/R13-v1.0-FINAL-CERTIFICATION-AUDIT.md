**A1 designation: Action Projection Runtime**

### GT-03: Naming Conflict

GT-01 ≠ GT-02. A0 names RT-13 "Action Runtime"; A1 names RT-13 "Action Projection Runtime." This is a genuine naming conflict between constitutional sources. A0 governs by constitutional authority precedence. The specification must disclose this conflict.

### GT-04: Responsibilities — Exact List from A0 §3.14 (verbatim, 14 entries)

1. Receive authorized CivilizationalDecisions from RT-12
2. Form Action Projection objects for each decision requiring external reality projection
3. Execute the seven-stage Action Projection Lifecycle: Decision Formation → Authority Validation → Effect Expectation Registration → Irreversibility Classification → Boundary Crossing → External Execution → Observed Consequence Registration and Reality Fabric Update
4. Classify irreversibility of every Action Projection before crossing the Projection Boundary (D5 PI-8) — this classification is constitutional and cannot be deferred
5. Register Effect Expectations for every Action Projection before crossing the Projection Boundary
6. Validate Projection Authority with RT-02 (Stage 2 of Action Projection Lifecycle)
7. Submit Action Projection to RT-03 for gate processing before Projection Boundary crossing
8. Cross the Projection Boundary into external reality and execute the action
9. Record all projected effects (D5 PI-6: consequence recording is mandatory)
10. Assign Projection Responsibility for all resulting effects (D5 Projection Responsibility Principle)
11. Enforce the distinction between internal Action Projection object and external action effect (D5 PI-2)
12. After crossing, register Observed Consequence signals with RT-08 for RT-14 to process
13. Enforce D5 PI-7 (Reality Overrides Representation): if external reality does not behave as expected, reality is the truth — never the plan
14. Obtain authorization from all affected domain authorities before projecting any Action that targets multiple domains; cross-domain Action Projection records must carry cross-domain authorization records issued by RT-03 (Constitutional Enforcement Kernel) (D5 PI-11)

**Count: 14 responsibilities.**
