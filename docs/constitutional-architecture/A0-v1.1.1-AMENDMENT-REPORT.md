## 3 — PROBLEM IDENTIFIED

### 3.1 The Inconsistency

A0 §4.1 Complete Runtime Dependency Graph, RT-07 (Memory) block contained:

```
RT-07 (Memory)
  └─→ RT-09 (historical Knowledge States)
  └─→ RT-10 (historical Understanding Models)
  └─→ RT-11 (historical CUMs, Deliberation Records)
  └─→ RT-04 (all historical records for audit)
```

This is a 4-entry dependent list. However, A0 §3.x establishes two additional RT-07 dependencies:

**A0 §3.9 (RT-08 — Observation Runtime):**
- Dependencies field: "RT-07 (historical state for contextualizing observations)"
- Consumed Constitutional Objects: "HistoricalStateQueryResult (from RT-07 — for contextualizing new observations against history)"

**A0 §3.15 (RT-14 — Reflection Runtime):**
- Dependencies field: "RT-07 (historical context)"
- Consumed Constitutional Objects: "historical Understanding Models (from RT-07 — for divergence context)"

Both relationships are constitutionally established within A0 itself. §4.1 is derived from §3.x and must reflect all §3.x-established relationships. The omission of RT-08 and RT-14 from §4.1's RT-07 block is therefore a §4.1 incompleteness relative to §3.x, not a new architectural claim.

### 3.2 Classification of the Inconsistency

**Type:** Omission (not wording error, ordering error, or structural contradiction)  
**Source:** §4.1 failed to enumerate two relationships already established in §3.9 and §3.15  
**Severity:** Class II (dependency graph incomplete) — no constitutional authority or responsibility affected  
**Pre-existing nature:** Both relationships have existed in §3.9 and §3.15 since A0 v1.0; the §4.1 omission is pre-existing

### 3.3 Secondary Inconsistency (Outside Scope)

A0 §3.8 (RT-07) Dependents field (line 781) also omits RT-08 and RT-14:

> *"Dependents: RT-09 (historical Knowledge States), RT-10 (historical Understanding Models), RT-11 (historical CUMs and Deliberation Records), RT-04 (all historical records)."*

This is the same omission in §3.8 as in §4.1. The approved amendment scope is §4.1. §3.8 is outside scope. This amendment does not modify §3.8. The §3.8 Dependents inconsistency is documented in Section 6 as a remaining item for a future editorial correction.

Note: A0 §3.8 Runtime Outputs (line 770) already contains the phrase "and other runtimes" after listing the primary recipients, which implicitly accommodates RT-08 and RT-14 without requiring amendment.
