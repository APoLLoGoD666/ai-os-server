## IMPLEMENTED FINDINGS

### DEF-001 — Authority Type Mischaracterization — RESOLVED

**Finding:** R6 v1.0 RS-06 claimed "Interpretation Authority (D6 §4.3)" for RT-06. This was constitutionally impossible: D6 §4.3 explicitly prohibits delegation to infrastructure runtimes; A0 §4.3 does not list RT-06; the derivation chain was unsupported.

**Implementation:**
- RS-06 §6.1 fully replaced: RT-06 holds no D6 AIR-N authority type. Constitutional authority is D3 §4 (GCR mandate) + D4 Stage 10 (Post-Commit Coherence Evaluation mandate), architecturally realized in A0 §3.7.
- RS-06 §6.2 corrected: Derivation chain is now D3 §4 → D4 Stage 10 → A0 v1.1 §3.7 → R0 → R6 v1.1. Note on supersession of v1.0 chain added.
- RS-06 §6.4 corrected: ADR-1 and ADR-2 compliance statements corrected; v1.0 failures noted.
- RS-02 §2.2 corrected: A0 §4.3 and A1 §5.1 rows updated to remove false authority claims.
- CERT-03 re-issued as PASS with corrected criteria.

**Adjudication basis:** RT06-CONSTITUTIONAL-AUTHORITY-RESOLUTION.md §2 (Phase 2); ADR-001.

**Verdict: RESOLVED in R6 v1.1**

### DEF-002 — Missing Inputs from RT-10 and RT-11 — RESOLVED (with adjudication modification)

**Finding:** R6 v1.0 RS-08 omitted Domain Understanding Model inputs from RT-10 and RT-11 as stated in A0 §3.7. The constitutional adjudication determined: A0 §3.7's "Domain Understanding Models from RT-10 and RT-11" was internally inconsistent with A0 §3.10 (RT-10 sends `UnderstandingDegradationFlag`, not `DomainUnderstandingModel`, to RT-06) and A0 §3.12 (RT-11 sends nothing to RT-06 — RT-11 depends on RT-06). The adjudication modified the original DEF-002 finding.

**Implementation (per adjudication, not per original deficiency register):**
- RS-08: Added `UnderstandingDegradationFlag` from RT-10 as input. DEF-002 note explaining adjudication finding added.
- RS-08: RT-11 NOT added as a source (adjudication found RT-11 sub-claim invalid).
- RS-26: RT-10 added as dependency with correct object name. DEF-002 note confirming RT-11 is not a dependency.
- CERT-04: Updated to include RT-10 in dependency check.

**Deviation from original deficiency register:** The original DEF-002 recommended adding both RT-10 and RT-11 as sources with "Domain Understanding Models." The adjudication (which supersedes the deficiency register) found: (a) correct object is `UnderstandingDegradationFlag` from RT-10; (b) RT-11 sub-claim is INVALID. Only RT-10 / `UnderstandingDegradationFlag` is implemented. Pending A0-v1.1-CORRIGENDUM-001 will correct A0 §3.7's imprecise consumed-object naming.

**Adjudication basis:** RT06-CONSTITUTIONAL-AUTHORITY-RESOLUTION.md §3 (Phase 3); ADR-002.

**Verdict: RESOLVED in R6 v1.1 (per adjudication)**
