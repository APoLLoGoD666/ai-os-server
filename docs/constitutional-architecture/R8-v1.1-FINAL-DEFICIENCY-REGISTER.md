### PRIOR FIND-001 — NOW RESOLVED

**Prior classification:** Class III (Editorial/Traceability)
**Prior location:** RS-06 §6.1 — Authority Class, AIR integrity rule heading
**Prior finding:** Heading "AIR-1 Authority Integrity Rule (D6 §4.7 AIR-3)" conflated two distinct AIR numbering systems: R0 §3.5 AIR-1 = Observation Authority type; D6 §4.7 AIR-1 = Authority Separation rule. The heading appeared to reference D6 §4.7 AIR-1 (Authority Separation) while the parenthetical revealed the actual source as D6 §4.7 AIR-3 (No Knowledge Monopolization). Body text then used "AIR-3" in the authority type sense (Decision Authority — RT-12), creating internal inconsistency.

**Resolution verification (independent):**
Read R8-v1.1 RS-06 §6.1 directly. The heading now reads: "D6 §4.7 Authority Integrity Rule AIR-3 (No Knowledge Monopolization — Observation/Interpretation Separation)." This heading is unambiguous: it identifies the document (D6 §4.7), the rule type (Authority Integrity Rule), the rule number (AIR-3), and the rule name (No Knowledge Monopolization). The body text now uses "authority type AIR-1" and "authority type AIR-2" to distinguish authority types (R0/A1 §5.1 sense) from D6 §4.7 rule numbers. The original conflating heading "AIR-1 Authority Integrity Rule (D6 §4.7 AIR-3)" does not appear anywhere in R8-v1.1.

**Status: RESOLVED.**

### PRIOR FIND-002 — NOW RESOLVED (was blocking)

**Prior classification:** Class II (Material Specification Defect) — BLOCKING
**Prior location:** RS-29 Loop 2 description; RS-31 Phase Ownership table; CERT-07 self-assessment
**Prior finding:** R8-v1.0 characterized RT-08 as "Supporting runtime" for the Observation of Consequence loop phase. A1-v1.2 §15.2 table places "RT-14 → RT-08" in the Primary Runtime column for this phase (Supporting Runtimes column contains "RT-07, RT-06"). R8-v1.0 misread the §15.2 table. This caused CERT-07 to fail.

**Resolution verification (independent):**
Read A1-v1.2 §15.2 directly (lines 1725–1736 of A1-v1.2-canonical.md). The table row for Observation of Consequence reads: "| Observation of Consequence | RT-14 → RT-08 | RT-07, RT-06 |" — confirming "RT-14 → RT-08" IS the Primary Runtime column entry. "RT-07, RT-06" are Supporting.

Read R8-v1.1 RS-29 Loop 2: RT-08 position states "Primary runtime (in sequence with RT-14) — the RT-14 → RT-08 sequence constitutes the primary pathway for Observation of Consequence per A1-v1.2 §15.2." The word "Supporting" is absent from this description.

Read R8-v1.1 RS-31 introductory sentence: "RT-08 is Primary runtime (in sequence with RT-14) for the Observation of Consequence phase per A1-v1.2 §15.2." Table row states "Primary Runtime (in sequence with RT-14)."

Searched R8-v1.1 for any remaining "Supporting" characterization of RT-08 for the Observation of Consequence phase: NONE FOUND.

Read CERT-07 check table: row states "Primary runtime role (in sequence with RT-14) for Observation of Consequence phase per A1-v1.2 §15.2, matching §15.2 Primary Runtime column placement of 'RT-14 → RT-08' | PASS."

**Status: RESOLVED. The characterization now exactly matches A1-v1.2 §15.2. CERT-07 self-assessment is PASS.**
