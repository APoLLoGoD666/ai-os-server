## 2. IMPLEMENTED FINDINGS

### 2.1 FIND-001 — RS-06 §6.1 AIR Nomenclature Disambiguation (Class III)

**Status: IMPLEMENTED**

**Finding summary:** The heading "AIR-1 Authority Integrity Rule (D6 §4.7 AIR-3)" conflated two independent "AIR-N" numbering systems that coexist in the constitutional architecture: R0 §3.5 defines AIR-1 through AIR-5 as authority type designations (AIR-1 = Observation Authority, AIR-2 = Interpretation Authority, AIR-3 = Decision Authority, AIR-4 = Projection Authority, AIR-5 = Audit Authority), while D6 §4.7 defines a separate set of Authority Integrity Rules also numbered AIR-1 through AIR-5 (AIR-1 = Authority Separation, AIR-2 = No Unauthorized Projection, AIR-3 = No Knowledge Monopolization, AIR-4 = No Hidden Decisions, AIR-5 = Audit Independence). The heading read "AIR-1 Authority Integrity Rule" (implying D6 §4.7 AIR-1 = Authority Separation) while citing "(D6 §4.7 AIR-3)" (= No Knowledge Monopolization). Additionally, the body text used "AIR-3" in the R0 §3.5 sense (Decision Authority — RT-12), creating internal inconsistency.

**Changes implemented:**
- CH-005: RS-06 §6.1 heading replaced with "D6 §4.7 Authority Integrity Rule AIR-3 (No Knowledge Monopolization — Observation/Interpretation Separation)" — unambiguously identifying the D6 §4.7 rule by both number and name
- CH-005: Body text "AIR-1 — Observation" and "AIR-2 — Interpretation" qualified as "authority type AIR-1" and "authority type AIR-2" to distinguish R0 §3.5 authority types from D6 §4.7 rule numbers
- CH-012: CERT-03 check row updated to describe the corrected heading

**Verification:** RS-06 §6.1 now references D6 §4.7 AIR-3 by full name (No Knowledge Monopolization) and uses "authority type AIR-N" when referencing R0 §3.5 authority types. The conflation is eliminated. The substantive content (rule quotation, separation principle, RT-08 may not hold Interpretation Authority) is unchanged.

### 2.2 FIND-002 — RS-29/RS-31 Loop Phase Characterization Correction (Class II — BLOCKING)

**Status: IMPLEMENTED**

**Finding summary:** R8-v1.0 characterized RT-08 as "Supporting runtime" for the Observation of Consequence phase. A1-v1.2 §15.2 table row for this phase is: "Observation of Consequence | RT-14 → RT-08 | RT-07, RT-06." The Primary Runtime column contains "RT-14 → RT-08" — placing the entire sequence in the Primary column. The Supporting Runtimes column contains "RT-07, RT-06" — not RT-08. R8-v1.0 misread the §15.2 table and assigned RT-08 to Supporting when A1-v1.2 §15.2 places RT-08 (jointly with RT-14) in the Primary column. This caused CERT-07 to fail (criterion: "RS-29 exactly matches A1 §15.2 for this runtime") and partially affected CERT-10.

**Changes implemented:**
- CH-004: RS-02 §2.2 A1-v1.2 §15.2 row corrected from "Supporting" to "Primary runtime (in sequence with RT-14)"
- CH-008: RS-29 Loop 2 Participants line: "(supporting)" → "(primary, in sequence)"
- CH-009: RS-29 Loop 2 position: "Supporting runtime — responds to RT-14 trigger" → "Primary runtime (in sequence with RT-14) — the RT-14 → RT-08 sequence constitutes the primary pathway for Observation of Consequence per A1-v1.2 §15.2"; constitutional basis citation corrected
- CH-010: RS-31 introductory sentence: "participating as a supporting runtime" → "Primary runtime (in sequence with RT-14)"
- CH-011: RS-31 Phase Ownership table row: "Supporting Runtime" → "Primary Runtime (in sequence with RT-14)"
- CH-013: CERT-07 check row: criterion updated from "Supporting runtime role" to "Primary runtime role (in sequence with RT-14)"; PASS verdict confirmed
- CH-014: CERT-10 A1-v1.2 §15.2 check row updated to affirm corrected Primary characterization

**Verification:** RS-29 Loop 2 position now states "Primary runtime (in sequence with RT-14)" matching A1-v1.2 §15.2 Primary Runtime column. RS-31 table row for Observation of Consequence states "Primary Runtime (in sequence with RT-14)." CERT-07 criterion now exactly matches the corrected RS-29 content and self-assesses PASS. The functional description (RT-08 applies full OPL, all Observation Record requirements apply, RT-14 sends ConsequenceObservationTrigger) is unchanged — only the positional characterization changed.

**CONDITION 1 from certification verdict:** Satisfied. RS-29 Loop 2 now characterizes RT-08 as Primary (in sequence with RT-14) for Observation of Consequence per A1-v1.2 §15.2. RS-31 is corrected accordingly. CERT-07 self-assessment is re-confirmed as PASS.

### 2.3 FIND-003 — RS-06 §6.2/§6.4 Authority Derivation Chain Extension (Class I)

**Status: IMPLEMENTED**

**Finding summary:** RS-06 §6.2 authority derivation chain stopped at "A0-v1.1.1 §3.9 → R0 → R8 v1.0" without citing A0-v1.1.1 §4.3 (Authority Relationship Graph) or A1-v1.2 §5.1 (Authority Type Distribution table). R0 CERT-03 requires the trace "D6 type definition → A0 §4.3 instantiation → A1 §5.1 entry" for every RS-06 authority claim. A1-v1.2 §5.1 explicitly confirms RT-08 holds AIR-1 and AIR-4. The authority itself was substantively correct — the deficiency was a traceability and citation gap.

**Changes implemented:**
- CH-006: RS-06 §6.2 derivation chain extended to: "...→ A0-v1.1.1 §3.9 (RT-08 constitutional specification — authority assigned) → A0-v1.1.1 §4.3 [Authority Relationship Graph] → A1-v1.2 §5.1 [Authority Type Distribution — confirms RT-08 holds AIR-1 and AIR-4] → R0 v1.0 (specification standard) → This document (R8 v1.1)"
- CH-007: RS-06 §6.4 ADR-1 statement extended to include "A0-v1.1.1 §4.3 and A1-v1.2 §5.1 confirm the authority assignment" for both AIR-1 and AIR-4 derivation statements
- CH-012: CERT-03 check row updated to reflect the extended chain including A0 §4.3 and A1-v1.2 §5.1

**Verification:** RS-06 §6.2 now contains the complete CERT-03-required chain: D6 type definition → A0 §3.9 → A0 §4.3 → A1 §5.1 → R0 → R8 v1.1. ADR-1 compliance statement references both A0 §4.3 and A1 §5.1. No authority assignments were changed. No authority scope was altered.

**CONDITION 2 from certification verdict:** Satisfied (recommended). RS-06 §6.2 and §6.4 now include A1-v1.2 §5.1 as an explicit citation in the derivation chain.
