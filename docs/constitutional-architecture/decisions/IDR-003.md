## Decision Required

**Is `ConsequenceObservationRecord` owned by RT-08 (Observer Runtime) or RT-14 (Consequence Runtime)?**

This decision determines:
- Which type file contains the `ConsequenceObservationRecord` schema
- Which runtime's `RUNTIME_ID` is stamped onto the type
- Whether W1-06 creates the type (current sequencing plan) or W1-11 creates it (if moved to RT-14)

---

## The Ownership Ambiguity

### Source 1 — Points to RT-08 ownership (I1-SEQUENCING, A0, A0.v1.0)

**I1-IMPLEMENTATION-SEQUENCING.md §W1-06** lists `ConsequenceObservationRecord` as one of the five types to be created in W1-06 under RT-08:

> Types to create: `ObservationRecord`, `ObserverRegister`, `ObservationChannelRecord`, `ConsequenceObservationRecord`, `ObserverLimitationRecord`

The task assigns the type to `lib/constitutional-types/observation-record.js`, the RT-08 type file.

**A0-v1.1.1 §3.8 (RT-08 — Observer Runtime):**

> **Owned Constitutional Objects:** ObservationRecord; ObserverRegister; ObservationChannelRecord; **ConsequenceObservationRecord**; ObserverLimitationRecord.

> **Produced Constitutional Objects:** ObservationRecord (routed to RT-03 for processing, then to RT-09); **ConsequenceObservationRecord** (for RT-14 when triggered by consequence observation).

**A0-v1.1.1 §3.14 (RT-14 — Consequence Runtime):**

> **Owned Constitutional Objects:** ObservedConsequenceRecord; CausalModelDivergenceRecord; OpenActionRegisterTerminalStatusRecord; ReflectionTriggerRecord.

> **Consumed Constitutional Objects:** **ConsequenceObservationRecord (from RT-08)**; EffectExpectationRecord (from RT-13); historical Understanding Models (from RT-07 — for divergence context).

**A0-v1.1.1 data flow diagram:**

> RT-08 ─[ConsequenceObservationRecord]─→ RT-03 ─→ RT-05 ─→ RT-14

**A0-v1.0-canonical.md §RT-08 (earlier baseline — consistent with v1.1.1):**

> **Owned Constitutional Objects:** ObservationRecord; ObserverRegister; ObservationChannelRecord; **ConsequenceObservationRecord**; ObserverLimitationRecord.

**Constitutional weight of Source 1:** A0 is the Architectural Axiom document — the highest-authority non-constitutional document in the APEX specification hierarchy. Both A0-v1.0 and A0-v1.1.1 consistently place `ConsequenceObservationRecord` in RT-08's owned objects. I1-SEQUENCING was derived from A0. These sources form a consistent position.

### Source 2 — Points to RT-14 ownership (I1-ARCHITECTURE)

**I1-IMPLEMENTATION-ARCHITECTURE.md §4.2** (the planning document): reportedly assigns `ConsequenceObservationRecord` to RT-14.

The exact text has not been verified in this IDR. The Implementation Owner must read I1-ARCHITECTURE §4.2 directly to confirm whether the assignment is explicit or inferred.

**Constitutional weight of Source 2:** I1-ARCHITECTURE is an implementation planning document. It derives from the A-series and R-series, but does not override them. Where a planning document conflicts with A0, the A-series governs.

**Rationale:**

`ConsequenceObservationRecord` is constitutionally an observation product, not a consequence product. When RT-13 consequence signals produce a need for external reality observation post-projection, that observation must cross the Projection Boundary. RT-08 holds exclusive AIR-4 inbound Projection Boundary authority (D3 RF-A6 — Observation Primacy). All inbound Projection Boundary crossings, including consequence observation triggers, are RT-08's constitutional function. RT-08 applies the full Observation Projection Lifecycle (D5 Part 3 Stages 1–3) to the consequence context and forms the record.

The authority evidence is unanimous at the A-series and R-series levels:

- A0-v1.1.1 §3.9 explicitly lists `ConsequenceObservationRecord` in RT-08's Owned Constitutional Objects.
- A0-v1.1.1 §3.15 explicitly lists `ConsequenceObservationRecord` in RT-14's Consumed Objects — not its Owned Objects.
- R8-v1.1-canonical.md RS-07: "Ownership is exclusive to RT-08. No other runtime may create, modify, or close these objects."
- R14-v1.0-canonical.md RS-07 explicitly states: "ConsequenceObservationRecord (RT-08 owned) — RT-14 consumes this for comparison; does not own it."
- R14-v1.0-canonical.md RS-04.2 (RT-08/RT-14 Boundary): "ConsequenceObservationRecord: produced by RT-08 (owned by RT-08) — raw observational data on what external reality produced."
- I1-IMPLEMENTATION-SEQUENCING §W1-06 lists `ConsequenceObservationRecord` as one of the five types for RT-08.
- I1-IMPLEMENTATION-SEQUENCING §W1-11 does NOT list `ConsequenceObservationRecord` for RT-14.

The sole conflicting source (I1-ARCHITECTURE §4.2) is a planning-level document subordinate to A0 and R-series. Its cited constitutional authority for the RT-14 assignment (R14-v1.0 RS-07) directly contradicts its assertion. No weight is given to an implementation planning document when it conflicts with A0 and all R-series specs, and when its own cited source undermines it.

The constitutional distinction is preserved: RT-08 owns the raw observational input (what external reality produced after the action); RT-14 owns the comparative consequence assessment output (what diverged between expectation and reality). `ConsequenceObservationRecord` is the former. `ObservedConsequenceRecord` is the latter.
