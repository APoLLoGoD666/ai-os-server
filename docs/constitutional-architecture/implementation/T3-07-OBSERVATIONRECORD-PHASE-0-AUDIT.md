## 2. BLOCKING CONSTRAINT ANALYSIS

### Constraint 1 — `authority_ref` (CRITICAL, DOCUMENTED, NOT RESOLVED)

`ObservationRecord.authority_ref` is `required: true` in the constitutional type schema. It references an RT-02 `AuthorityResolutionResult`. RT-02 is absent (governance-meta.js is 58 bytes). D8 INV-4 prohibits fabricating this reference.

**Consequence:** `ObservationRecord.create()` cannot be called — `_create()` validates required fields and throws `TypeError` if `authority_ref` is absent. This eliminates schema-validated constitutional type instantiation.

**Resolution approach:** Build the ObservationRecord data object manually without calling `ObservationRecord.create()`. Stamp `__type: 'ObservationRecord'`, `__runtime: 'RT-08'`, `__baseline: 'APEX-CONSTITUTION-v1.0'`, `__version: '1.0.0'` manually. Persist to constitutional-store. The record is constitutionally honest in its present fields; `authority_ref` is absent (not fabricated) and documented as T3-08 scope.

**This is NOT fabrication.** Absent ≠ fabricated. The constitutional store records honest partial records for auditability.

**Precedent:** Wave 2 ActorProfile (W2-12) used a synthetic `actor_id` ('FOUNDER-APEX') documented as limitation L-01. Manual construction with documented absent fields follows the same honesty standard.

### Constraint 2 — Observation Channel (RESOLVED IN T3-07)

No `ObservationChannelRecord` exists. T3-07 creates `lib/reality/observation-channel-registry.js` (bootstrap, same pattern as T3-06). The channel `'APEX-FABRIC-CHANNEL'` is registered at first emission.

### Constraint 3 — Observer Limitation (RESOLVED IN T3-07)

No `ObserverLimitationRecord` infrastructure exists. T3-07 creates `lib/reality/observer-limitations.js` with `createObserverLimitationRecord()`. Each ObservationRecord emission concurrently creates a limitation record, satisfying RT08-INV-3.
