The following guidance is issued for the benefit of R9 specification, informed by audit experience with R8.

Before beginning R9 specification, verify RT-09 identity against source documents:

1. **Canonical name:** Read A0-v1.1.1 §3.10 section header directly. The canonical name is whatever A0 §3.10 states. A0 governs.

2. **A1-v1.2 §3.0 conflict check:** Read A1-v1.2 §3.0 Runtime Reference Summary for the RT-09 row. A1-v1.2 §3.0 lists RT-09 as "Epistemic Processing Runtime" at T3 — the name differs from A0 §3.10 ("Knowledge Runtime"). If A1-v1.2 §3.0 designates RT-09 with a different name or tier from A0 §3.10, this conflict must be disclosed in RS-01 and RS-13 of R9, following the same pattern established in R8. A0 governs identity; A1 §3.0 conflict is disclosed but not determinative.

R8 audit confirmed that RT-08's PAIRs (though named under the incorrect "Observation Projection Runtime" label in §3.0) were constitutionally correct characterizations. Verify this for RT-09 PAIRs before adopting them.

### Loop Phase Discipline (FIND-002 Lesson)

The FIND-002 finding arose from misreading the A1-v1.2 §15.2 table structure. For R9 specification:

1. **Read A1-v1.2 §15.2 directly.** The table has two columns: "Primary Runtime" and "Supporting Runtimes." For each phase where RT-09 participates, confirm which column its identifier appears in.

2. **A1-v1.2 §15.2 for RT-09 participation:**
   - Evidence phase: "RT-09 | RT-06, RT-07" — RT-09 is PRIMARY
   - Knowledge phase: "RT-09 (advanced) | RT-15" — RT-09 is PRIMARY
   - Updated Understanding phase: "RT-09 → RT-10 → RT-11 | RT-15" — RT-09 is PRIMARY (in sequence)
   - RT-09 appears in Supporting column for no phase.

3. **No assumptions.** Read the source before specifying RS-29 and RS-31 for R9.

### Authority Derivation Chain (FIND-003 Lesson)

For R9, RS-06 §6.2 must include the complete CERT-03 chain:
- D6 authority type definition → A0 §4.3 instantiation → A1-v1.2 §5.1 entry → R0 → R9

Read A1-v1.2 §5.1 for RT-09: "RT-09 | Evidence domain | Evidence→Knowledge | — | — | —" — RT-09 holds AIR-1 (Evidence domain observation) and AIR-2 (Interpretation Authority for Evidence→Knowledge). Cite this explicitly in R9 RS-06 §6.2.

### AIR Nomenclature (FIND-001 Lesson)

For R9, RS-06 §6.1 must maintain clear separation between:
- R0/A1 authority type labels (AIR-1 = Observation, AIR-2 = Interpretation, AIR-3 = Decision, AIR-4 = Projection, AIR-5 = Audit)

When citing D6 §4.7 rules in RS-06 §6.1, use the full heading form "D6 §4.7 Authority Integrity Rule AIR-N (Rule Name)" to avoid ambiguity. When using authority type labels, use the qualifier "authority type AIR-N" consistently throughout RS-06 §6.1.
