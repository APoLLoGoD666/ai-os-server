### FAA-09-001

| Field | Value |
|-------|-------|
| Finding ID | FAA-09-001 |
| Classification | Class III — Editorial |
| Section | RS-06 (Authority) |
| Location | RS-06 derivation chain; specifically the citation "D6 §4.2 → A0 §4.3 → A1 §5.1 → R0 ADR-1 → RS-06" |
| Constitutional Basis | R0 RQ-5 (Citation Precision) |
| Severity | Advisory only |

**Description**

R9 RS-06 cites A0 §4.3 as a step in the derivation chain that "instantiates" RT-09's specific AIR-1 and AIR-2 authority assignments. A0 §4.3 is the constitutional authority relationship graph — a high-level diagram showing that RT-02 grants authority to actors via RT-15. It does not contain a per-runtime AIR assignment table.

The per-runtime authority instantiation (the table that explicitly assigns AIR-1 and AIR-2 to RT-09) is located in A1 §5.1 (Authority Distribution table). A0 §4.3 establishes the framework from which A1 §5.1 derives, but citing A0 §4.3 as the instantiation point overstates the specificity of what A0 §4.3 literally contains.

**Evidence**

A0 §4.3 (read verbatim): Contains the authority relationship graph showing RT-02 as authority granter and RT-15 as the delegation conduit. It is a structural diagram, not a per-runtime AIR assignment table.

A1 §5.1 (read verbatim): Contains the Authority Distribution table with explicit runtime rows. The RT-09 row reads: AIR-1 (Evidence domain), AIR-2 (Evidence→Knowledge). This is the actual per-runtime instantiation.

**Remediation (Advisory)**

Consider amending the RS-06 derivation chain to: "D6 §4.2–4.3 (authority type definitions) → A1 §5.1 (per-runtime instantiation) → R0 ADR-1 → RS-06" with a note that A0 §4.3 establishes the structural framework from which A1 §5.1 derives the specific assignments.

This remediation is advisory. The current citation is not constitutionally wrong — A0 §4.3 is a valid intermediate in the logical derivation chain — but tightening the citation would improve traceability precision.

**Certification Impact**

None. This finding does not affect any CERT criterion. R9 is UNCONDITIONALLY CERTIFIED notwithstanding this advisory observation.
