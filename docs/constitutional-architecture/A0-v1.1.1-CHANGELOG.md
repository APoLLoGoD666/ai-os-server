### Change 002 — §4.1 RT-07 Dependent List: Add RT-08 and RT-14

**Section:** §4.1 Complete Runtime Dependency Graph — RT-07 (Memory) block

**Original:**
```
RT-07 (Memory)
  └─→ RT-09 (historical Knowledge States)
  └─→ RT-10 (historical Understanding Models)
  └─→ RT-11 (historical CUMs, Deliberation Records)
  └─→ RT-04 (all historical records for audit)
```

**Replacement:**
```
RT-07 (Memory)
  └─→ RT-08 (HistoricalStateQueryResult — historical context for contextualizing new observations)
  └─→ RT-09 (historical Knowledge States)
  └─→ RT-10 (historical Understanding Models)
  └─→ RT-11 (historical CUMs, Deliberation Records)
  └─→ RT-14 (historical Understanding Models — consequence divergence context)
  └─→ RT-04 (all historical records for audit)
```

**Constitutional reason:**

**RT-08 addition:** A0 §3.9 (RT-08 — Observation Runtime) explicitly lists RT-07 in its Dependencies field: "RT-07 (historical state for contextualizing observations)." A0 §3.9 Consumed Constitutional Objects includes "HistoricalStateQueryResult (from RT-07 — for contextualizing new observations against history)." The dependency RT-08 → RT-07 is constitutionally established by §3.9. The §4.1 graph, which must reflect all §3.x-established dependency relationships, omitted this relationship. The addition corrects the omission.

**RT-14 addition:** A0 §3.15 (RT-14 — Reflection Runtime) explicitly lists RT-07 in its Dependencies field: "RT-07 (historical context)." A0 §3.15 Consumed Constitutional Objects includes "historical Understanding Models (from RT-07 — for divergence context)." The dependency RT-14 → RT-07 is constitutionally established by §3.15. The §4.1 graph omitted this relationship. The addition corrects the omission.

**Note on RT-14 bidirectionality:** A0 §4.1 already contains `RT-14 → RT-07 (Observed Consequence Records for persistence)`, representing RT-14 writing to RT-07 for persistence. The new `RT-07 → RT-14` entry is a distinct, non-redundant relationship: RT-07 providing historical context to RT-14. Both directions are independently established in §3.x and are not contradictory.

**Note on ordering:** RT-08 inserted before RT-09 (ascending numerical order). RT-14 inserted after RT-11 and before RT-04 (ascending numerical order, with RT-04 retained last per existing pattern for audit-function runtimes). Ordering is editorial, not constitutional.

**Audit finding addressed:** R7-v1.1-CERTIFICATION-VERDICT.md CERT-04 condition — "A0 §4.1 amendment to add RT-08 and RT-14 as explicit RT-07 dependents."

**Constitutional basis:** A0 §3.9 Dependencies (RT-07); A0 §3.9 Consumed Objects (HistoricalStateQueryResult from RT-07); A0 §3.15 Dependencies (RT-07); A0 §3.15 Consumed Objects (historical Understanding Models from RT-07).

**Impact assessment:** §4.1 dependency graph corrected to reflect §3.x-established relationships. No runtime responsibilities changed. No authority changed. No objects changed. No invariants changed. R7-v1.1 CERT-04 CONDITIONAL PASS condition is fully resolved by this change. R7-v1.1-canonical.md RS-27 Extended Dependents (RT-08, RT-14) receive A0 §4.1 bijection status; CERT-04 will advance from CONDITIONAL PASS to PASS upon R7-v1.1 re-certification or formal acknowledgment of this amendment.

### Change 003 — §4.2 RT-07 Information Flow: Add RT-08 and RT-14

**Section:** §4.2 Information Flow Graph — RT-07 HistoricalStateQueryResult flow line

**Original:**
```
RT-07 ─[HistoricalStateQueryResult]─→ RT-09, RT-10, RT-11, RT-04
```

**Replacement:**
```
RT-07 ─[HistoricalStateQueryResult]─→ RT-08, RT-09, RT-10, RT-11, RT-14, RT-04
```

**Constitutional reason:** §4.2 Information Flow Graph derives from and must be consistent with §4.1 Dependency Graph. After Change 002 establishes RT-08 and RT-14 as recipients of RT-07 HistoricalStateQueryResults in §4.1, §4.2's corresponding flow line must reflect the same recipients. Leaving §4.2 inconsistent with §4.1 would create a new intra-Part-4 contradiction in A0 v1.1.1 (§4.1 would show RT-07 → RT-08, RT-07 → RT-14; §4.2 would not). This is a necessary consequential consistency fix, not an independent new finding.

**Note on §3.8 Runtime Outputs (line 770):** §3.8 Runtime Outputs already says "HistoricalStateQueryResults (to RT-09, RT-10, RT-11, RT-04, and other runtimes)" — the phrase "and other runtimes" implicitly includes RT-08 and RT-14, so §3.8 line 770 does not require amendment. §3.8 Dependents field (line 781) does not include RT-08 and RT-14 — this is a pre-existing §3.x inconsistency outside the approved scope of this amendment (see Amendment Report §6: Remaining Items).

**Audit finding addressed:** Phase 4 consistency verification requirement — "No new constitutional issues introduced."

**Constitutional basis:** Same as Change 002 (A0 §3.9 and §3.15 establish the HistoricalStateQueryResult flow to RT-08 and RT-14).

**Impact assessment:** §4.2 information flow graph corrected to reflect complete HistoricalStateQueryResult routing established in §3.x. No responsibilities, authority, objects, or invariants changed. Fully consistent with Change 002.
