### Detailed Analysis of Lines 366, 374, and 410

**Line 366 — `last_decision_ref`:**

The RS-11 state variable table describes `last_decision_ref` as: "Reference to most recent CivilizationalDecision — Updated on delivery."

Process 3 Step 12 (line 451) specifies: "Update `last_decision_ref` and clear `deliberation_active`" — this step occurs immediately after "Deliver to RT-12 (PAIR 40, DLVR permission)" at step 11.

At the moment of step 12 execution, RT-11 has delivered a CivilizationalDecisionProposal to RT-12. RT-12 has not yet formed the CivilizationalDecision. The state variable is labeled as a reference to "most recent CivilizationalDecision" but is updated at the moment of Proposal delivery — before the CivilizationalDecision exists.

Assessment: The label "Reference to most recent CivilizationalDecision" is semantically inaccurate. At the point of update, what RT-11 has produced and delivered is a CivilizationalDecisionProposal, not a CivilizationalDecision. This creates an imprecision: the state variable name implies RT-11 tracks RT-12's output object (CivilizationalDecision), which belongs to RT-12. However, the update timing (at delivery of the Proposal, before RT-12 forms the Decision) suggests the variable is tracking the Proposal delivery event, not managing RT-12's object.

This is not a Class I defect (RT-11 does not claim to own, manage, or produce the CivilizationalDecision object itself), but it is a Class III defect: the state variable description contains an imprecise label that attributes tracking of RT-12's owned object to RT-11's state. The correct label should be "Reference to most recent CivilizationalDecisionProposal delivered to RT-12."

**Line 374 — "State changes that produce CivilizationalDecisions":**

The full RS-11 State Persistence statement reads: "All state must be persisted through RT-03 kernel mediation for Class A state transitions. State changes that produce CivilizationalDecisions or modify CUM version are Class A operations."

The phrase "State changes that produce CivilizationalDecisions" attributes the production of CivilizationalDecisions to RT-11 as a Class A state transition. This is a boundary violation statement. RT-11 does not produce CivilizationalDecisions — RT-11 produces CivilizationalDecisionProposals. RT-12 produces CivilizationalDecisions.

Assessment: The phrase "produce CivilizationalDecisions" in the context of RT-11's state persistence is constitutionally inaccurate. However, it can be read as describing the broader system-level outcome (i.e., the state change sequence that eventually results in a CivilizationalDecision being formed by RT-12). The document elsewhere (RS-07, RS-10) is explicit that RT-11 does not produce CivilizationalDecisions. However, the language is imprecise and constitutes a Class III defect. It does not rise to Class I or Class II because: (a) the broader document unambiguously and repeatedly assigns CivilizationalDecision production to RT-12, and (b) no ownership or management claim is made here — only an imprecise description of state persistence classification.

**Line 410 — "For every CivilizationalDecision, RT-11 must:":**

The full passage reads: "Constitutional deliberation is governed by the Deliberation Architecture. For every CivilizationalDecision, RT-11 must: [followed by deliberation steps]"

This phrasing uses "CivilizationalDecision" as a shorthand for "every civilizational decision process" to mean "whenever the system is going to produce a CivilizationalDecision, RT-11 must execute deliberation." This is consistent with A0 §3.12 R4 ("Conduct constitutionally governed Deliberation (D7 Part 4)") and A0 §3.12 R5 ("Enforce the deliberation principle: civilizational decisions formed without deliberation are constitutionally void").

Assessment: The phrasing is imprecise but not a boundary violation. RT-11 is describing its deliberation obligations that precede every CivilizationalDecision formation event. This is Class IV (editorial/traceability) — imprecise language that does not constitute an ownership or production claim.

### RS-03 and RS-04 — CivilizationalDecisionProposal Usage

RS-03 Purpose section correctly uses "CivilizationalDecisionProposal" throughout. RS-04 Scope correctly uses "CivilizationalDecisionProposal production (RT-11 produces proposals; RT-12 forms the CivilizationalDecision)." These are constitutionally correct.
