Returns `parts.join('\n\n')` — a single concatenated string of Master PII.

## 5. User Exposure Analysis (7 questions)

1. **User calls voice-chat.js → alexContext constructed?** — **YES.** Both the greeting path (line 79) and the full-context path (line 90) invoke `buildAlexContext()` with no identity gate.
2. **alexContext sent to LLM in User's request context?** — **YES.** Line 143 places it in the `system` array unconditionally; `.filter(Boolean)` on line 153 keeps non-empty entries.
3. **alexContext contains Master-private values?** — **YES.** Both components in §4 are Master-private.
4. **User can indirectly learn Master-private info through model output?** — **YES.** Any User prompt like "What do you know about the person you serve?" produces a response conditioned on Alex's Obsidian profile + Layer 9 facts.
5. **alexContext returned directly in HTTP response?** — **NO.** Route only returns `{ ok, reply }`. This does not mitigate the leak — the reply text is derived from a Master-conditioned system prompt.
6. **Identity gate before alexContext construction?** — **NO** (pre-remediation). **YES** (post-remediation, see §7).
7. **User A receives User B's private data through alexContext?** — **NO.** alexContext is exclusively Master-scoped; there is no per-user data mixing. Cross-user leakage is Master→User only.

## 7. Remediation

**Approach:** Option A from the phase brief — gate the entire `buildAlexContext()` invocation behind `req.identity.role === 'master'`. Chosen because:

- Users need no Master identity context (the general system prompt at lines 154-156 and the memory/wiki/docs slots remain populated regardless).
- Matches the pattern already sanctioned by P0-I3 (`req.identity?.role === 'master'` gate at line 238 for Obsidian transcript writes) — no new architecture invented.
- Identity source is `req.identity`, server-resolved by `resolveIdentity` (`lib/middleware.js:196-233`) from the JWT. Never from `req.body`, `req.headers.role`, or `req.query.role` (grep confirms none of these exist in the file).
- Fails closed: `req.identity?.role` on missing identity evaluates to `undefined`, and `undefined !== 'master'` blocks construction.

**Exact diff (`routes/voice-chat.js`, +8/-2):**

```diff

+        // profile + Alex-tagged Layer 9 facts. It is Master-private and must never reach

+        // role from req.identity; fail closed on missing identity (undefined !== 'master').
+        const _vcIsMaster = req.identity?.role === 'master';
```
